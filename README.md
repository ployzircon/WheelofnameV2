# 🎡 วงล้อสุ่มชื่อนักเรียน (Classroom Wheel of Names)

เว็บแอปพลิเคชันสุ่มชื่อนักเรียนสำหรับคุณครูและห้องเรียน **ไม่มีโฆษณา 100%** โทนสีฟ้าสดใส สบายตา ใช้งานง่าย ฟังก์ชันครบครัน รองรับการฉายจอโปรเจกเตอร์ สมาร์ตโฟน และแท็บเล็ต

![Classroom Wheel of Names](https://raw.githubusercontent.com/ployzircon/WheelofnameV2/main/preview.png)

---

## ✨ จุดเด่นและฟังก์ชันการใช้งาน

- 🎯 **วงล้อฟิสิกส์สมจริง:** มีการเร่งความเร็วและชะลอการหมุนอย่างเป็นธรรมชาติ เข็มชี้กระดิกตามช่องชื่อ
- 🔊 **ระบบเสียงในตัว (Web Audio API):**
  - เสียงติ๊ก (Tick Sound) ขณะหมุน ปรับระดับเสียงตามความเร็วการหมุน
  - เสียงฉลองชัยชนะ (Victory Fanfare & Chimes)
  - สามารถเปิด/ปิดเสียงได้ทันที
- 🎊 **เอฟเฟกต์พลุเฉลิมฉลอง (Confetti Explosion):** แสดงชื่อผู้โชคดีตัวใหญ่ชัดเจน พร้อมตัวเลือกลบชื่อออก/เก็บไว้
- 🏫 **ระบบจัดการห้องเรียน (Classroom Presets):**
  - บันทึกรายชื่อได้หลายห้อง (เช่น ม.1/1, ม.1/2, ป.6/1)
  - ข้อมูลบันทึกอยู่ในเครื่องอัตโนมัติ (LocalStorage)
- 📝 **จัดการรายชื่อได้อย่างยืดหยุ่น:**
  - วางรายชื่อจาก Excel หรือพิมพ์ทีละบรรทัดได้ทันที
  - สลับตำแหน่งชื่อ (Shuffle) และเรียง ก-ฮ / A-Z
  - นำเข้า (Import) และส่งออก (Export) ไฟล์ `.txt`
- 🖥️ **โหมดโปรเจกเตอร์เต็มจอ (Fullscreen Mode):** กดปุ่มเต็มจอเพื่อแสดงเฉพาะวงล้อขนาดใหญ่สำหรับฉายหน้าชั้นเรียน
- 🎨 **ธีมสีหลากหลาย:** ธีมหลัก **ฟ้าสดใส (Sky Blue)**, สีรุ้งสดชื่น, พาสเทล, ลูกกวาด, เขียวมินต์, ส้มซันเซ็ต
- ⚡ **ปรับเวลาหมุนได้:** ตั้งแต่ 3 วินาที (เร็วทันใจ) ถึง 20 วินาที (ลุ้นระทึก)
- ⌨️ **คีย์ลัดสะดวก:** กด <kbd>Spacebar</kbd> เพื่อหมุน และ <kbd>Esc</kbd> เพื่อปิดหน้าต่าง

## 🚀 การ Deploy บน Vercel

เว็บนี้เป็น Static Web Application ที่พร้อมใช้งานบน Vercel ทันที:
1. เข้าไปที่ [Vercel](https://vercel.com)
2. กด **Add New...** > **Project**
3. Import repository `WheelofnameV2` จาก GitHub
4. กด **Deploy** ได้ทันทีโดยไม่ต้องตั้งค่า Build Command เพิ่มเติม
